# 사용 가이드

## 서버 연결

화면의 **연결 설정**에서 서버 주소와 토큰을 입력합니다.

| 요청                          | 인증                                |
| ----------------------------- | ----------------------------------- |
| 상태 조회·명령·신고·경로 탐색 | 관제 토큰 (`Authorization: Bearer`) |
| STOMP 연결                    | CONNECT 프레임의 관제 토큰          |
| 스마트폰 위치 전송            | 장치 토큰 (`X-Device-Token`)        |

토큰은 메모리에만 보관하고 새로고침하면 지웁니다. 소스나 환경 변수에 토큰을 넣지 않습니다.

서버의 `CORS_ALLOWED_ORIGINS`에 프론트 주소를 등록합니다. 서버 기본 허용 주소는 `http://localhost:3000`과 `http://localhost:5173`입니다. 카카오 개발자 콘솔에도 프론트의 사이트 도메인을 등록해야 지도가 표시됩니다.

서버가 시간대 없는 시각을 반환하므로 서버와 브라우저의 시계·시간대를 맞춰 사용합니다. `.env`를 수정한 뒤에는 개발 서버를 다시 실행합니다.

## 화면별 동작

| 주소        | 화면               |
| ----------- | ------------------ |
| `/`         | 대시보드           |
| `/map`      | 안전 지도          |
| `/history`  | 이동 기록          |
| `/reports`  | 위험 신고          |
| `/alerts`   | 위험 알림          |
| `/location` | 스마트폰 위치 전송 |

기존 `/routes`와 `/statistics`는 각각 `/map`과 `/history`로 이동합니다.

### 대시보드와 위험 알림

- 거리는 cm, 기울기는 °, 속도는 m/s로 표시합니다. 위험도는 서버가 판단한 1–5점을 사용합니다.
- 수신하지 못한 값은 `값 없음`으로 표시합니다. 센서는 3초, GPS는 5초 이상 갱신되지 않으면 끊김으로 표시합니다.
- 실시간 연결은 `/ws`의 STOMP를 사용합니다. 센서·연결 상태·신고·위험 알림을 구독하며, 끊기면 5초 간격으로 재접속합니다.
- 알림 소리는 **알림 소리 켜기** 버튼을 누른 뒤 사용할 수 있습니다. 위험 알림 내역은 접속 중에만 남습니다.
- 자동 정지 명령을 보내지 못한 경우 긴급 배너를 표시합니다. 명령의 전송 완료는 실제 동작 완료와 다르므로 현장에서 확인해야 합니다.
- 이동 명령의 기본 시간은 1초이며, **즉시 멈추기** 버튼으로 정지 명령을 보낼 수 있습니다.

### 지도와 이동 기록

- 지도는 로보독이 실제로 다닌 길을 기준으로 표시합니다. 길이 충분히 수집되지 않으면 경로를 찾지 못할 수 있습니다.
- 안전 우선은 위험 구간을 피하고, 최단 거리는 위험도를 고려하지 않습니다.
- 지도에 표시하는 로보독 위치는 마지막 수신 위치입니다.
- 이동 기록은 기간 미지정 시 최근 1,000건, 기간 지정 시 최대 10,000건을 조회합니다. 화면에서는 50건씩 보여줍니다.

### 신고와 사진

- 민원 창구 자동 연동은 아직 없습니다. 직접 접수한 뒤 받은 접수번호를 등록합니다.
- 승인 대기·제출 실패 상태에서 접수번호를 등록하거나 기각할 수 있습니다. 이미 처리된 신고는 최신 상태를 다시 조회합니다.
- 카메라는 선택 기능입니다. 켜면 3초마다 최신 프레임 주소를 조회합니다. 신고 사진 주소는 상세 화면을 열 때와 4분마다 갱신합니다.
- S3가 설정되지 않았거나 사진이 없으면 해당 상태를 안내합니다.

## 스마트폰 위치 전송

1. 스마트폰에서 `/location`을 엽니다.
2. **연결 설정**에서 서버 주소와 장치 토큰을 입력합니다.
3. **위치 전송 시작**을 누르고 위치 권한을 허용합니다.
4. 화면을 켜둔 채 이 페이지를 유지합니다.

위치 오차가 30m를 넘으면 정확한 위치를 기다립니다. 전송 중지 버튼을 누르거나 화면을 나가면 위치 추적을 해제합니다. 화면 꺼짐 방지는 지원되는 브라우저에서만 동작합니다.

위치 기능은 HTTPS 또는 `localhost`에서 사용할 수 있습니다. HTTPS 화면에서는 API와 WebSocket도 HTTPS/WSS로 제공해야 합니다. 스마트폰의 `localhost`는 스마트폰 자신이므로 PC의 서버 주소나 HTTPS 도메인을 입력합니다.

위치 전송만으로 이동 기록이 만들어지지는 않습니다. 아두이노·로보독의 센서 전송이 함께 필요합니다.

## 확인 범위

API 인증·오류 처리, 실시간 상태 갱신, 신고 처리, 경로 요청, GPS 권한·정확도·중지 처리를 테스트합니다. CI에서는 포맷·린트·테스트·빌드를 실행합니다.

브라우저 화면은 로컬 테스트 응답으로 확인했습니다. 실제 서버·로보독·스마트폰 GPS·카카오 지도·S3를 연결한 확인은 별도로 필요합니다. `docs/screenshots`의 이미지는 테스트 데이터로 촬영한 참고 화면입니다.

## 협업 규칙

- `main`은 배포용, `dev`는 개발 통합용으로 사용합니다. 모든 작업은 `dev`를 거칩니다.
- 작업마다 이슈와 브랜치를 만들고 기능별로 PR을 분리합니다. 커밋도 작업 단위로 나눕니다.
- PR은 일반 PR로 열고, 요청 없이 머지하지 않습니다.
- 이슈와 PR 담당자는 `jiwoo1222`로 지정합니다.
- 신규 기능·개선은 `enhancement`, 오류 수정은 `fix` 라벨을 사용합니다.

| 커밋 타입  | 용도             |
| ---------- | ---------------- |
| `feat`     | 새로운 기능      |
| `fix`      | 오류 수정        |
| `design`   | 디자인 변경      |
| `style`    | 코드 스타일 변경 |
| `refactor` | 구조 개선        |
| `docs`     | 문서 수정        |
| `revert`   | 커밋 되돌리기    |
| `test`     | 테스트 추가·수정 |
| `chore`    | 기타 작업        |
