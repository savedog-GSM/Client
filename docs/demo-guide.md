# 해커톤 시연

화면 오른쪽 아래 **발표 시작**을 누르면 기능별 안내가 열립니다.

- **예시 데이터로 시작**: 로봇과 백엔드 없이 센서·경로·제어·알림·신고·위치 전송을 보여줍니다.
- **실제 연결로 시작**: 연결 설정의 서버와 실제 로봇을 사용합니다.
- 발표 가이드를 접어도 선택한 모드는 유지됩니다. 시연 모드 상단에서 실제 연결로 전환할 수 있습니다.

## 3분 발표 순서

| 순서 | 화면 | 보여줄 내용 |
| --- | --- | --- |
| 1 | 대시보드 | 전방 거리, 기울기, 위험도, 지도와 추이 |
| 2 | 경로 | 주소로 출발지·도착지 선택 후 안전 우선과 최단 거리 비교 |
| 3 | 로봇 제어 | 제어 패널을 열어 전진·정지 요청, 카메라 확인 |
| 4 | 통계 | 시간 범위를 지정해 센서 기록 조회 |
| 5 | 알림 | 대시보드에서 위험을 선택한 뒤 자동 정지 알림 확인 |
| 6 | 위험 신고 | 대기 신고 선택 → 사진 확인 → 예시 접수번호 `DEMO-001` 입력 → 접수 완료 |
| 7 | 위치 전송 | 시작·중지 버튼과 마지막 성공 시각 확인 |

시연 모드는 `/?demo=1&present=1`로 바로 열 수 있습니다. 처음 상태로 돌아가려면 상단의 **시연 초기화**를 누르세요. 예시 신고 처리 결과는 새로고침하면 초기화됩니다.

## 발표 전 확인

- 지도와 주소 검색은 인터넷, 카카오 JavaScript 키, 등록된 웹 도메인이 필요합니다.
- 시연 모드의 센서·GPS·경로·사진은 예시입니다. 경로는 실제 보행 안내용이 아닙니다.
- 실제 모드는 HTTPS API와 WebSocket 연결, 로봇 연결, 필요한 토큰을 확인하세요.
- 실제 위치 전송은 HTTPS 화면을 스마트폰에서 열고 위치 권한을 허용하세요. 위치 오차가 30m를 넘으면 전송을 기다립니다. PC 위치는 오차가 클 수 있습니다.
- 실제 제어 버튼은 로봇을 움직입니다. 실제 모드에서 명령을 누르기 전에 이동 공간을 확인하세요.
- 신고 접수번호 등록은 서버에 처리 상태를 기록하는 기능입니다. 외부 기관에 자동으로 신고하지 않습니다.

## PR 반영 순서

시연 모드 #63 → 발표 가이드 #64 → 빠른 상황 시연 #65 순서로 dev에 반영하세요. 직접 접속 설정 PR은 다른 기능과 독립적입니다. 모든 PR의 대상은 dev입니다.
