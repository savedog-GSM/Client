# 경로 및 실시간 연결 점검

## 401 인증 실패

웹의 연결 설정에서 서버에 설정된 `OPERATOR_API_TOKEN` 값을 관제 토큰에 입력합니다. 장치 토큰은 `DEVICE_API_TOKEN`이며 서로 바꿔 쓸 수 없습니다. 관제 토큰은 메모리에만 보관되어 새로고침하면 다시 입력해야 합니다.

프론트는 관제 요청에 `Authorization: Bearer <관제 토큰>`을, 센서·위치 전송에는 `X-Device-Token`을 사용합니다. 실제 토큰을 소스 코드나 VITE 환경 변수에 넣지 않습니다.

토큰 없는 실제 서버의 `/api/robot/status`와 `/api/paths/search` 요청에서 401 및 `UNAUTHORIZED`를 확인했습니다. 인증을 적용한 이후의 경로 응답은 별도 확인이 필요합니다.

## 경로 탐색 404

개발자 도구의 Network에서 `POST /api/paths/search`의 응답 본문 `code`를 확인합니다.

- `PATH_NOT_FOUND`: API는 실행됐지만 연결 가능한 수집 경로가 없습니다.
- `NOT_FOUND` 또는 HTML 404: 서버 주소·배포 버전·프록시 경로를 점검합니다.

현재 서버 main의 경로 엔진은 일반 도로 데이터가 아닌 로보독의 위험도 수집 기록으로 그래프를 만듭니다. 출발·도착지 각각 30m 이내에 연결 가능한 지점이 있어야 하며, 기록 간 수신 간격이 10초를 넘으면 연속 이동 간선으로 연결하지 않습니다. 안전 우선에서는 위험 구간을 제외합니다. 스마트폰 위치 전송만으로 이 기록이 만들어지는 것은 아닙니다.

광주소프트웨어마이스터고등학교에서 송정공원역까지 탐색하려면 그 사이를 연결하는 실제 수집 기록이 필요합니다. 일반 도로 전체의 보행 안내가 필요하면 백엔드에 보행 경로 공급자 연동이 추가로 필요합니다.

웹에서는 출발·도착지를 선택한 뒤 카카오맵 도보 길찾기를 새 창으로 열 수 있습니다. 외부 길찾기의 결과를 로보독 안전 경로로 표시하지 않습니다. 시연 좌표는 외부 길찾기로 보내지 않습니다.

URL 형식은 [카카오 지도 공식 가이드](https://apis.map.kakao.com/web/guide/#routeurl)의 `/link/by/walk/이름,위도,경도/이름,위도,경도`를 사용합니다.

## WebSocket 502

`wss://savedog.https.gsmsv.site/ws`의 502는 토큰 없는 REST 요청의 401과 구분해 점검합니다.

백엔드 담당자는 `/ws` 업스트림 가용성, WebSocket Upgrade 전달, 허용 Origin에 실제 배포 웹 주소가 포함되는지 확인합니다. STOMP CONNECT에는 REST와 같은 관제 토큰이 필요합니다. 제공된 로그에는 일시적 인터넷 연결 끊김·DNS 오류도 있으므로 현재 네트워크 복구 후 새 연결의 결과를 확인합니다.

토큰이나 서버 로그를 공개 이슈에 붙이지 않습니다.
