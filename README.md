# 지켜멍

로보독의 실시간 센서 상태와 안전 경로를 확인하기 위한 React + TypeScript 대시보드입니다.

## 실행

```bash
npm install
npm run dev
```

## 주요 화면

- 대시보드: 현재 안전 상태, 센서값, 추천 경로, 최근 알림
- 경로 탐색: 이동 거리와 위험도를 비교하고 경로 실행
- 이동 통계: 센서/경로 데이터를 요약해 확인
- 위험 알림: 위험 및 주의 상황을 시간순으로 확인

## UI 원칙

- 장식용 아이콘 최소화
- 중요한 상태와 숫자를 먼저 보여주는 정보 우선순위
- 한 화면에서 다음 행동을 바로 찾을 수 있는 구조
- 모바일에서도 사용할 수 있는 반응형 레이아웃
- 위험/주의/정상 상태를 색상과 텍스트로 함께 표시
